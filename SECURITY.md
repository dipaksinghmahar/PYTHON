## Reporting a Vulnerability

We take security vulnerabilities seriously. If you discover a security issue in this project, please report it privately.

### How to Report

**Do not** open a public GitHub issue. Instead, send an email to the project maintainer at the address listed in the commit history or repository profile.

Please include the following details in your report:

- A clear description of the vulnerability
- Steps to reproduce the issue (proof of concept, screenshots, or code snippets are helpful)
- Affected versions or commit hashes
- Any potential impact you have identified

### What to Expect

- **Acknowledgement:** You will receive an acknowledgement of your report within 48 hours.
- **Updates:** We will provide status updates every **7 days** until the issue is resolved or a decision is made.
- **Accepted:** If the vulnerability is accepted, we will work on a fix and release it as soon as possible. You will be credited in the release notes (unless you prefer to remain anonymous).
- **Declined:** If the vulnerability is determined to be out of scope or a false positive, we will explain our reasoning and may suggest alternative reporting channels (e.g., upstream dependencies).
- **Embargo:** We kindly ask that you refrain from publicly disclosing the vulnerability until we have had a reasonable opportunity to address it (typically 90 days from the initial report).
